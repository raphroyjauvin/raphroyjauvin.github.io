# raphroyjauvin.ca

Personal portfolio of Raphaël Roy-Jauvin: geospatial data engineering, GIS, and urban planning. Live at [raphroyjauvin.ca](https://www.raphroyjauvin.ca), hosted on GitHub Pages.

## Structure

```
index.html        English site (single page)
fr/index.html     French version
de/index.html     German version
images/           Banner, project thumbnails, and diagrams
files/            Resume PDFs and project documents
CNAME             Custom domain configuration
```

## Stack

- Hand-coded HTML, CSS, and vanilla JavaScript. No frameworks, no build step.
- Typography: Newsreader, Archivo, and IBM Plex Mono, served from Google Fonts.
- Each language version is a self-contained page; all three share the same structure and styling.
- Analytics: Umami Cloud.

## Working on the site

1. Clone the repo and open the folder in VS Code.
2. Preview with the Live Server extension, or open `index.html` directly in a browser.
3. Commit and push to `main`. GitHub Pages redeploys automatically within a minute or two.

Larger experiments happen on a branch and merge into `main` once approved.
